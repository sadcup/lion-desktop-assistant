# 小狮子本地桌面助手 PRD

版本 1.0 · 本机 Linux X11 · 目标用户为当前登录用户

## 1. 产品目标

用户通过桌面上的 3D 小狮子，用一句普通话或文字发起常用电脑操作。助手应该能找到目标、明确展示会发生什么、执行后给出可以核对的结果。核心场景是打开常用应用、继续处理最近的文件、整理图片、读资料和生成工作笔记。

交互入口包括双击桌宠、长按桌宠录音、应用菜单，以及已打开面板内的快捷按钮。桌宠继续支持左键拖动、右键转动视角和短按反馈。语音采用主动录音，长按桌宠约半秒开始，松开后继续录音，约 2.4 秒无说话声后发送。桌宠语音单段上限 30 秒。录音与回复提示显示在桌宠旁，长按不会打开面板。实时显示录音状态，面板内手动录音最长约 12 秒。文字输入支持 Enter 发送和 Shift+Enter 换行。

## 2. 用户流程和验收标准

| 编号 | 用户故事 | 功能及交互 | 验收 |
| --- | --- | --- | --- |
| A1 | 我想打开 Chrome 或桌面 | 文字或语音提交。常用明确指令直接调用桌面桥，面板显示执行结果 | Chrome 出现真实窗口。桌面文件夹正常打开。语音路径有可见转写和可播放回复 |
| A2 | 我想看看刚编辑过哪些文件 | 面板「最近文件」快捷按钮。按修改时间显示最近七天的本地文档和图片，最多八项，支持从清单点击打开 | 用近期和过期测试文件验证排序、时间筛选和打开路径。应用不会暴露隐藏文件 |
| A3 | 我只记得文档主题 | 从允许目录按标题或部分正文查找。支持最近时间筛选。唯一明确候选可按要求打开，有歧义时显示候选 | 用标题不含关键词的文档验证命中，再核对真实打开结果 |
| A4 | 我想批量整理图片 | 支持移动单张图片，也支持把某目录下的图片或明确列出的多张图片移到另一目录。一次最多 20 张，不递归。计划包含每张图片的来源和目标 | 确认前文件位置不变。取消无副作用。同名冲突时在移动前拒绝整批。成功后校验原路径消失及目标文件字节一致 |
| A5 | 我想建一个目录或整理资料 | 新建文件夹需确认。多份文档可按主题读取、提取待办，输出来源并草拟笔记。笔记写入需确认 | 核对两份来源各自的事实，确认后写入笔记，取消时保持原样 |
| A6 | 我需要理解当前窗口 | 面板「看屏幕」使用本地模型读画面，同时显示系统提供的窗口标题。可按已有桌面桥能力查询窗口和系统状态 | 读屏请求在本机完成。可见窗口标题与真实窗口一致。画面描述单独标注 |
| A7 | 我想知道到底执行了什么 | 面板显示成功和失败的文件操作记录、来源文件及确认计划。会话重开面板后仍可查看记录 | 核对确认通过、取消、同名失败的回执。重新打开面板，已经执行的记录仍可查看 |

## 3. 界面与状态

1. 面板顶部放置「看屏幕」「最近文件」「新对话」。正文为对话记录，底部为文字输入、录音和语音回复开关。
2. 读取期间显示处理状态并禁用重复提交。执行失败显示具体原因。录音结束或面板关闭即释放麦克风。
3. 文件确认卡展示名称、完整路径和每个文件的去向。用户可确认或取消。同一个确认只执行一次。
4. 「最近文件」在面板内显示文件名和路径，点击行内按钮打开对应文件。操作结果显示在对话里。时间依据文件修改时间。
5. 文件批处理遇到同名、重复来源或不支持的路径，优先在执行前报错。执行中若遇外部修改，会尝试回退已完成的移动，并报告需要人工处理的剩余项。

## 4. 文件和桌面操作边界

- 文件根目录为桌面、文档、下载、图片和项目目录。隐藏路径、密钥和越界路径继续由桌面桥拒绝。
- 打开应用和文档按明确指令执行。新建目录、移动文件、写笔记、发送键鼠操作需要确认。
- 批量移动限定普通图片、现有目标目录及同一文件系统。保留原文件名，使用操作系统提供的禁止覆盖移动。目录范围、数量上限和筛选条件在确认卡可见。
- 查文档、读屏和语音处理在本机。文字模型通过允许列表调用桌面工具。读屏是辅助理解，视觉输出不能作为点击坐标。
- 本版范围为上述 A1–A7。任意网站自动操作、跨文件系统迁移、删除文件、后台常听和跨操作系统支持属于独立需求。

## 5. 实现顺序

1. 保留并回归现有桌宠、语音、搜索、确认和单文件操作。
2. 增加最近文件接口与面板入口，并绑定文件项的打开动作。
3. 增加图片批量计划与确认，验证冲突和取消。
4. 补齐对话回执与重新打开面板后的恢复。
5. 在当前桌面运行端到端验收。记录已验证的能力及环境限制。

## 6. 验收记录

- 语音使用合成普通话样本，核对了转写、真实 Chrome 窗口和生成的 WAV。真人语音识别仍受麦克风与环境影响。
- 最近文件通过真实 Electron 面板打开了测试文档。接口验证了排序、范围和未列出路径的拒绝。
- 批量移动以两张内容不同的 PNG 验证了预览、取消、同名保护、文件变化保护、内容一致性和重复确认保护。冲突发生在预览后、执行前的用例已覆盖。执行中出现外部竞态后回退的分支未做破坏性注入测试。
- 两份测试周报完成了查找、引用来源、草拟待办、确认并写入。读屏接口在本机返回了画面描述。
- 面板关闭后重新打开，文件操作记录仍可查看。记录随 BOLT 会话保存，重启后台服务或新建对话会清空当前面板记录。
